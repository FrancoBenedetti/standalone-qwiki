# Customizing Themes

Qwiki includes a built-in **Theme Editor** that allows you to write raw CSS directly from the browser.

## How to access the Theme Editor
1. Click the **⚙️ Settings** button in the header.
2. Click **🎨 Open Theme Editor** at the bottom of the modal.

## Editing an existing theme
1. Select a theme from the dropdown menu and click **Load**.
2. Make your desired CSS changes in the editor text area.
3. Keep the filename the same and click **Save Theme** to overwrite the existing theme.

## Creating a new custom theme
1. Load an existing theme that is close to what you want (e.g., `theme-default.css`).
2. Make your customizations.
3. Change the "Save As" filename to something new. **Note:** Your filename *must* start with `theme-` and end with `.css` (e.g., `theme-mycompany.css`).
4. Click **Save Theme**.

Your new theme will immediately be available in the dropdown menus for the site, categories, and individual documents!
