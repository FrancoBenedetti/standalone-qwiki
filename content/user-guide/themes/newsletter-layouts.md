# Newsletter Layout Themes

These themes are specifically designed for "bulletin" style content that is meant to be scanned quickly.

## Theme: Highlights (`theme-newsletter-highlights.css`)
This theme is highly opinionated and transforms standard Markdown into a beautiful email-style newsletter.

**Features:**
* **Centered Headings**: All headings are centered for a dramatic effect.
* **Narrow Column**: The reading width is restricted to 800px, which is optimal for short paragraphs.
* **Circular Images**: Any image you add is automatically styled as a circle and centered.
* **Dotted Dividers**: Standard horizontal rules (`---`) become elegant dotted dividers.

*Best for: Weekly team updates, company announcements, or feature highlights.*

## Theme: Minimal (`theme-newsletter-minimal.css`)
A stark, high-contrast theme for when the content needs to speak for itself.

**Features:**
* **Uppercase Typography**: Main headings are bold, uppercase, and spaced out.
* **Monochrome Images**: All images are automatically converted to grayscale.
* **Centered Blockquotes**: Quotes are huge and centered between thick borders.

*Best for: Artistic essays, design updates, and bold statements.*
