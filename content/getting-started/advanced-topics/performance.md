# Performance Optimization

This document is located inside a **nested sub-folder** (`getting-started / advanced-topics / performance`).

## Key Techniques

- **Caching**: Published Google Docs and Markdown documents are rendered efficiently on the server.
- **Minimal Dependencies**: Standalone Qwiki requires zero heavy frameworks or external SaaS APIs.
- **Nested Folder Routing**: Support for `?folder=advanced-topics` or `?dir=advanced-topics` query parameters.
