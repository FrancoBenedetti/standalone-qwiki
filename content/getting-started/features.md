# Features & Capabilities

Standalone Qwiki supports three primary document types to give you maximum flexibility for technical documentation, user manuals, and specifications.

## 1. Local Markdown Files (`.md`)
* Native support for GitHub-flavored Markdown.
* Rendered server-side with fast performance and syntax highlighting.
* Editable directly in the browser with **Admin Rights**.

## 2. Published Google Docs (`gdoc`)
* Direct integration with Google Docs "Publish to Web".
* Automatic HTML parsing & cleaning to match your site's theme.
* Maintains real-time updates when modified in Google Docs.

## 3. PDF Documents (`.pdf`)
* Embedded document preview with zoom and full-page viewing options.
* Great for official product datasheets, architecture charts, and compliance manuals.

---

### Admin Features
* Session-based login with simple configuration.
* In-app Markdown editor with live side-by-side preview.
* Drag-and-drop file upload for new PDFs and Markdown files.
